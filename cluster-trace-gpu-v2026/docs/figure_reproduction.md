# Figure Reproduction

This document describes how to reproduce paper figures from the public ASI GPU
trace fact tables.

## Installation

Use Python 3.10 or newer.  Install the plotting and Parquet dependencies from
the release root:

```bash
python -m pip install -r requirements.txt
```

## Workflow

The scripts read only the local Parquet fact tables under `data/`, build the
derived aggregates needed for the paper figures, and write outputs under
`data/derived/` and `figures/`.  No remote database access is required.

Generate paper aggregates and figure inputs from the public fact tables:

```bash
python scripts/build_aggregates.py \
  --data-root data \
  --out-root data/derived
```

Generate paper figures from those derived inputs:

```bash
python scripts/plot_figures.py \
  --data-root data/derived \
  --out-dir figures
```

List available figure names:

```bash
python scripts/plot_figures.py --list
```

Regenerate a subset:

```bash
python scripts/plot_figures.py \
  --figures gpu_spec_distribution,job_type_model_type_execution_time_cdf \
  --data-root data/derived \
  --out-dir figures
```

`scripts/build_aggregates.py` writes:

```text
data/derived/
  aggregates/
  figure_inputs/
  fact_derived_manifest.json
```

`scripts/plot_figures.py` writes PDFs/EPS files, summary CSV files, and small
manifest JSON files under `figures/`.

The aggregate builder is intentionally a single pass-oriented script so the
large fact tables do not need to be scanned once per figure.
